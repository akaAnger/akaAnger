# Подключение к Яндекс Диалогам

Код не прошивает Станцию и не подменяет штатную модель Алисы. Он работает как **отдельный навык**, который запускается по названию. Музыка, таймеры и умный дом остаются штатными возможностями Алисы, а не функциями этого проекта.

## Что нажимать

1. Откройте [консоль Яндекс Диалогов](https://dialogs.yandex.ru/developer/) под аккаунтом, к которому привязана Станция.
2. Создайте новый диалог типа **Навык в Алисе**. Выберите **Приватный** тип доступа.
3. Придумайте уникальное название из двух-трех понятных слов. В названии не должно быть слов «Алиса», «Яндекс», «Станция». Пример идеи — «Домашний собеседник Ильи», но занятость и распознавание любого примера нужно проверить.
4. Откройте **Общие сведения** и скопируйте **Идентификатор навыка**. Вставьте его в поле **ID навыка** нашей панели.
5. Убедитесь, что в панели выбран ИИ, заполнена модель и есть **публичный HTTPS-адрес сервера**. Сохраните настройки.
6. Скопируйте показанный панелью **Webhook URL**. В настройках навыка выберите **Backend → Webhook URL** и вставьте адрес целиком, включая `/alice/` и секрет. Это не API-ключ и не адрес сайта нейросети.
7. Заполните обязательные поля консоли, включая описание, контакты разработчика, примеры запуска и иконку. Можно использовать `assets/skill-icon.png` из проекта. Для колонки **не включайте** «Нужно устройство с экраном».
8. Во вкладке **Тестирование** отправьте «Привет», затем обычный вопрос. Если появилась фраза об ожидании, отправьте **Ответ готов?**. Убедитесь, что ответы приходят и не обрываются.
9. Отправьте навык на автомодерацию и после ее успешного завершения опубликуйте его с приватным доступом. Публикация не гарантируется самим кодом: решение и доступность сервиса зависят от Яндекса.
10. На своей Станции: **«Алиса, запусти навык [ваше название]»**. Проверка в консоли не заменяет этот шаг: там навык постоянно считается активным, и распознавание названия не тестируется.

Названия и расположение элементов интерфейса могут меняться. Актуальные требования: [настройки публикации](https://yandex.ru/dev/dialogs/alice/doc/ru/publish-settings), [приватный доступ](https://yandex.ru/dev/dialogs/alice/doc/ru/access).

## Текст для описания навыка

> Личный голосовой помощник для общения с выбранной языковой моделью. При долгой подготовке ответа скажите «Ответ готов?». Для продолжения длинного ответа — «Дальше», для очистки контекста текущей сессии — «Новая тема». Текст запросов передается выбранному ИИ-провайдеру. Не диктуйте пароли, платежные данные и конфиденциальную информацию.

Добавьте название реально выбранного провайдера, если этого требует ваш сценарий или правила площадки. Не называйте навык официальным продуктом Яндекса, OpenAI или другого поставщика.

## Почему требуется «Ответ готов?»

[Яндекс ждет ответ не более 4,5 секунды](https://yandex.ru/dev/dialogs/alice/doc/ru/publish-settings), включая сеть. Приложение ждет модель до 1,5 секунды и, если она еще не ответила, возвращает короткую реплику. Сам запрос продолжает выполняться на постоянно работающем сервере. Следующая команда получает результат **того же** запроса.

Колонка не может в этой реализации сама заговорить позднее без нового обращения пользователя. Медленная сеть, холодный запуск хостинга или недоступность сервера все равно могут нарушить срок платформы. Это не обход ограничения Яндекса и не гарантия времени ответа.

## Команды

| Команда | Действие |
|---|---|
| Обычный вопрос | Один запрос к выбранной модели |
| Ответ готов? | Забрать результат уже начатого запроса |
| Дальше / Продолжи | Следующая часть уже полученного длинного ответа |
| Повтори | Повторить последнюю произнесенную часть |
| Новая тема | Удалить локальный контекст этой сессии и отменить ее текущий запрос |
| Отмена | Прекратить ожидание текущего запроса; предыдущий контекст остается |
| Помощь | Объяснить команды без обращения к ИИ |
| Выход / Хватит / Стоп | Завершить навык |

Служебные команды не вызывают дополнительную генерацию. Отмена не гарантирует возврата оплаты: провайдер уже мог обработать запрос.

## Доступ для семьи

[Приватный навык](https://yandex.ru/dev/dialogs/alice/doc/ru/access) изначально доступен владельцу. Индивидуальный доступ другим людям выдается средствами Диалогов. Не делайте навык публичным просто ради доступа с вашей Станции.

Дополнительно в нашей панели можно заполнить список `session.user.user_id`. Это идентификатор пользователя именно для этого навыка, а не почта, логин или ID устройства. После разрешенного обращения он виден администратору по кнопке «Обновить адрес». Если список непустой, запрос без совпадающего пользовательского ID отклоняется.
