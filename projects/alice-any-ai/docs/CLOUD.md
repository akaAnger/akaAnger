# Запуск в облаке: без терминала

Этот путь рассчитан на новичка: компьютер можно выключать, HTTPS настраивает хостинг. Шаблон использует **платный Render Starter и постоянный диск 1 ГБ**. Проверьте итоговую стоимость в Render перед подтверждением. Проект сам ничего не покупает. Доступность регистрации, оплаты и API зависит от страны и выбранных сервисов.

## 1. Создайте свой экземпляр

Откройте [Deploy to Render](https://render.com/deploy?repo=https://github.com/akaAnger/akaAnger). Войдите в Render и проверьте выбранный репозиторий. Корневой `render.yaml` указывает на папку `projects/alice-any-ai`.

Если кнопка не открывает создание Blueprint, в Render выберите **New → Blueprint** и подключите `https://github.com/akaAnger/akaAnger`. В интерфейсе может потребоваться сначала сделать Fork репозитория в свой GitHub. Для самостоятельного репозитория используйте `render.yaml` из корня самого проекта, без `rootDir`.

Параметры шаблона:

| Параметр | Значение |
|---|---|
| Тип | Web Service, Node |
| Тариф | Starter, платный |
| Экземпляры | Один |
| Проверка запуска | `/healthz` |
| Папка данных | `/var/data/alice-any-ai` на постоянном диске |
| Секреты | Разные автоматически созданные `ADMIN_TOKEN` и `WEBHOOK_SECRET` |

Не добавляйте в GitHub ключ ИИ. Введете его позже в своей панели. Не используйте бесплатный засыпающий сервис как надежный вариант для колонки: холодный старт может не уложиться в [4,5 секунды Алисы](https://yandex.ru/dev/dialogs/alice/doc/ru/publish-settings). Особенности бесплатного Render описаны [у хостинга](https://render.com/docs/free).

## 2. Войдите в панель

После успешного развертывания откройте адрес своего Web Service, например `https://ваш-сервис.onrender.com`.

В настройках этого сервиса найдите **Environment → ADMIN_TOKEN**. Скопируйте значение и вставьте в поле **Ключ администратора** на открывшейся странице. Не путайте его с API-ключом нейросети.

Ключ нужен для входа в панель. Он не хранится в localStorage браузера. После перезагрузки страницы может понадобиться войти снова.

## 3. Подключите модель

Выберите сервис, вставьте его API-ключ и нажмите **Загрузить модели**. Выберите текстовую чат-модель из подсказок поля «Модель» или впишите ее точный идентификатор из кабинета провайдера.

Нажмите **Проверить связь с ИИ**. Это реальный запрос, за который провайдер может списать деньги. Панель покажет ответ и время получения. Длинное время не означает, что связка непригодна: предусмотрена команда «Ответ готов?».

Для «Другого совместимого API» нужно указать базовый адрес, например `https://api.example.com/v1`, а не страницу чата и не полный `/chat/completions`.

## 4. Создайте приватный навык

Следуйте [инструкции по Яндекс Диалогам](YANDEX.md): создайте навык, скопируйте его ID в панель и сохраните настройки. Облачный HTTPS-адрес панель обычно получает автоматически из `RENDER_EXTERNAL_URL`.

Скопируйте **Webhook URL** из панели в Яндекс Диалоги. Он содержит отдельный секрет, поэтому не выкладывайте его в скриншоты и посты.

## 5. Проверьте перед повседневным использованием

Сначала проверьте навык во вкладке «Тестирование», затем на настоящей Станции. После публикации спросите короткий вопрос, длинный вопрос, «Ответ готов?», «Дальше» и «Новая тема».

Храните только один запущенный экземпляр сервиса. Истории и незавершенные запросы находятся в его оперативной памяти. Перезапуск их удалит. Настройки на постоянном диске сохранятся. Это **не serverless-функция** и не приложение для GitHub Pages.

## Обновление

Автообновление из GitHub в шаблоне выключено. Перед ручным обновлением сделайте резервную копию папки данных в безопасное место. Нажмите Manual Deploy в Render после проверки изменений. Не публикуйте резервные копии: в них есть API-ключ.

При создании собственного Fork измените ссылку репозитория в своей копии корневого `render.yaml`, либо удалите поле `repo`, чтобы Blueprint использовал свой репозиторий. Не меняйте `rootDir`, пока проект лежит во вложенной папке.
