# На своем компьютере

Для первого знакомства не нужен VPS, Docker или домен. Нужны **Node.js 22 или новее**, утилита **cloudflared** для временного HTTPS-адреса и ключ выбранного ИИ. Компьютер и окно программы должны оставаться включенными.

Это путь для проверки. Временный адрес изменяется после перезапуска туннеля, поэтому для постоянного использования удобнее [облако](CLOUD.md) или постоянный туннель.

## Windows

1. Установите Node.js с [официального сайта](https://nodejs.org/). Выбирайте поддерживаемую LTS-версию 22 или новее. После установки закройте старые окна терминала.
2. Установите cloudflared по [официальной инструкции Cloudflare](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/). В Windows с работающим Winget можно открыть Терминал и выполнить:

   ```powershell
   winget install --id Cloudflare.cloudflared --exact
   ```

   Затем закройте терминал. Если Winget отсутствует, используйте официальный установщик/двоичный файл из инструкции и убедитесь, что `cloudflared` доступен в PATH.
3. На [странице репозитория](https://github.com/akaAnger/akaAnger) нажмите **Code → Download ZIP**, распакуйте архив и откройте `projects/alice-any-ai`. Самостоятельный архив проекта уже начинается с папки `alice-any-ai`.
4. Дважды нажмите **start.bat**. Скрипт не требует прав администратора, не отключает защиту Windows, не устанавливает пакеты npm и не скачивает исполняемые файлы из сети. Браузер откроет вашу локальную панель.
5. Выберите провайдера, вставьте его API-ключ, укажите модель и проверьте подключение. Кнопка проверки может вызвать списание у провайдера.
6. Когда в окне программы появится сообщение о готовом туннеле, нажмите **Обновить адрес** в панели. В поле появится `https://...trycloudflare.com`.
7. [Создайте приватный навык](YANDEX.md), скопируйте его ID в панель, сохраните настройки, а полученный Webhook URL вставьте в Диалоги.

Если браузер не открылся, скопируйте **личную ссылку настройки** из окна программы. Не публикуйте ее: в ней секрет панели. Фрагмент после `#` используется только при входе и удаляется из адресной строки.

Если Windows показывает предупреждение о скачанном BAT-файле, сначала прочитайте файл в Блокноте и проверьте источник. Не отключайте защиту системы ради запуска неизвестного кода. Альтернатива — открыть терминал в папке проекта и выполнить `node start.mjs --open --tunnel`.

## macOS и Linux

Установите Node.js и cloudflared из официальных источников. В папке проекта:

```sh
node start.mjs --open --tunnel
```

В macOS также есть `start.command`. Если архив не сохранил право запуска, выполните `chmod +x start.command`, либо используйте команду выше. Никаких `npm install` не требуется.

## Только локальная панель, без туннеля

```sh
node start.mjs --open
```

Так можно настроить и проверить ИИ, но Яндекс не сможет обратиться к `localhost`. Запуск без туннеля сам по себе не подключает колонку.

## Ollama

Установите [Ollama](https://ollama.com/), запустите ее и заранее скачайте подходящую текстовую модель. Выберите **Ollama** в панели, оставьте ключ пустым и загрузите список моделей.

Стандартный базовый адрес: `http://127.0.0.1:11434/v1`. В поле модели выберите реально установленный тег. Производительность зависит от модели, памяти и оборудования; никаких обещаний работы большой модели на любом ПК.

Если само приложение запущено в облаке, `127.0.0.1` указывает на облачный сервер, а не на домашний компьютер. Такой вариант не подключит домашнюю Ollama автоматически. Не открывайте ее незащищенный порт в интернет.

Даже с локальной моделью связка не становится офлайн: распознавание речи и ответы через навык проходят через Яндекс.

## Туннель и ограничения

[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) не требуют своего домена, но предназначены для разработки и не имеют гарантии доступности. Хостнейм меняется при каждом запуске. После изменения адреса обновите Webhook URL в Диалогах.

Флаг `--allowed-mail` использовать нельзя: он требует интерактивного входа через браузер, а запросы Алисы этого не умеют. Защита нашего вебхука — случайный секрет в пути плюс ID навыка и опциональный список пользователей.

Если cloudflared не стартовал, проверьте `cloudflared --version`, интернет и наличие старого конфига Cloudflare. Для отдельной диагностики:

```sh
cloudflared tunnel --url http://127.0.0.1:8787
```

Полученный HTTPS-домен можно вручную вставить в панель. Региональные сетевые ограничения и блокировки туннелей проект не устраняет.

## Где хранятся ключи

В папке `.data` рядом с программой. Не пересылайте ее и не добавляйте в Git. Для переноса на другой компьютер скопируйте ее отдельно по защищенному каналу. В Unix выставляются права 700 для новой папки и 600 для файла; в Windows проверьте права доступа своей учетной записи самостоятельно.

После первого запуска для входа используйте личную ссылку из окна программы. Чтобы полностью остановить сервер и туннель, нажмите Ctrl+C.
