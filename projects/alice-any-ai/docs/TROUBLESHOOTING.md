# Если что-то не работает

| Симптом | Что проверить |
|---|---|
| BAT сразу закрывается / node не найден | Установите Node.js 22+, закройте старый терминал. Файл запускайте из распакованной папки. |
| Панель просит пароль | Это ADMIN_TOKEN, а не API-ключ ИИ. Локально откройте личную ссылку из окна программы; в облаке возьмите значение из Environment. |
| Нет публичного HTTPS-адреса | Локальная программа не равна хостингу. Установите cloudflared и запускайте с `--tunnel`, либо разместите сервис в облаке. |
| «Не найдено» на секретном адресе в браузере | Вебхук рассчитан на POST из Яндекс Диалогов, не на открытие GET в браузере. Панель находится по корню домена. |
| Не найден идентификатор навыка | В Диалогах откройте Общие сведения. ID не равен названию навыка. |
| Ошибка 401 | Неверный, отозванный или не относящийся к этому сервису API-ключ. |
| Ошибка 402 | Проверьте баланс и условия API-провайдера. |
| Ошибка 403 | Доступ к модели, права ключа, регион сервера; либо неверный ID навыка на стороне нашего вебхука. |
| Ошибка 404 от API | Неправильное имя модели или базовый URL. Не вставляйте адрес сайта чата и не добавляйте `/chat/completions` вручную. |
| Ошибка 400 от API | Модель не поддерживает `max_tokens`, выбранную температуру или system-сообщения. Попробуйте `max_completion_tokens`, очистите дополнительные параметры; при несовместимом формате нужен другой адаптер. |
| API ответил, но текста нет | Возможно, это не чат-модель или весь лимит ушел на рассуждения. Выберите другую модель либо увеличьте лимит выходных токенов. |
| Список моделей не загрузился | Некоторые совместимые API не реализуют `/models`. Введите точный идентификатор вручную. |
| «Еще готовлю ответ» | Скажите «Ответ готов?» через несколько секунд. Это не повторная отправка вопроса. По умолчанию один запрос может ждать API до 60 секунд. |
| Ответ обрезан | Скажите «Дальше». Алиса ограничивает отдельную текстовую реплику 1024 символами, приложение делит длинный ответ. Слишком большой результат дополнительно ограничивается приложением. |
| Новый вопрос не принимается | Завершите получение предыдущего ответа или скажите «Отмена». Приложение не отправляет параллельные вопросы одной сессии без вашего решения. |
| «Навык не отвечает» от Алисы | Проверьте работающий сервер, полный HTTPS-адрес, сертификат, холодный старт хостинга, сетевой маршрут. Есть общий лимит Яндекса 4,5 секунды. |
| После перезапуска все пропало | История и ожидающие запросы только в RAM. Конфигурация должна лежать на постоянном диске; в Docker используйте volume. |
| После перезапуска локальный адрес перестал работать | У Quick Tunnel новый домен. Обновите HTTPS-адрес в панели и Webhook URL в Диалогах. |
| Ollama работает дома, но не в облаке | `127.0.0.1` в облаке относится к облачному серверу. Запустите приложение рядом с Ollama или настройте защищенный сетевой доступ самостоятельно. |
| Навык есть в тестировании, но не вызывается на колонке | Нужны публикация, правильный аккаунт и распознаваемое уникальное название. В тестовой консоли активационное имя не проверяется. |

## Что приложить к issue

Версию Node.js, ОС/хостинг, провайдера и имя модели, воспроизводимые шаги, обезличенный код ошибки. Не прикладывайте `.data`, `.env`, API-ключи, ссылку администратора, полный Webhook URL, личные вопросы и идентификаторы пользователей.

## Чего здесь нет

Полной замены Алисы; гарантированной совместимости со всеми API; платного ChatGPT через обычную подписку; доступа к браузеру модели; поиска в интернете; инструментов и умного дома; фонового самопроизвольного озвучивания; переноса истории между устройствами; промышленного многопользовательского биллинга.

Совместимость конкретного провайдера нужно проверять его реальным ключом. Название пресета означает реализованный формат запроса, а не подтвержденную автором работу всех моделей сервиса.
