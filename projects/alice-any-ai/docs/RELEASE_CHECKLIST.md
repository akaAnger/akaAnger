# Перед анонсом

Статус версии 0.1.0: программный прототип с автоматическими тестами. Реальную Станцию, регистрацию/модерацию навыка, инфраструктурный деплой и платные API необходимо проверить отдельно.

- [ ] Установить по README на чистой Windows-системе, не пользуясь знаниями автора.
- [ ] Проверить установку через Render и сохранность настроек после перезапуска.
- [ ] Подключить реальный ключ выбранного провайдера; проверить модель и списания.
- [ ] Пройти публикацию приватного навыка.
- [ ] На настоящей Станции проверить первый вопрос, ответ с контекстом, ожидание, «Ответ готов?», «Дальше», «Повтори», «Новая тема», «Отмена», «Выход».
- [ ] Повторить тест как минимум со вторым API-форматом или локальной Ollama.
- [ ] Проверить отказ чужому пользователю и работу после перезапуска.
- [ ] Записать ОС, модель Станции, провайдера, модель ИИ и дату проверки без секретов.
- [ ] Снять скриншот панели без API-ключей, ID пользователей, секретного Webhook URL и личной ссылки администратора.
- [ ] В посте назвать реально проверенные варианты, а не обещать работу с любой нейросетью без исключений.
- [ ] Поставить ссылку на действующую страницу проекта и честно назвать внешний сервер/API и возможную оплату.

Не представлять автоматические тесты с фиктивным API как тесты реальной колонки. До ручной проверки не ставить статус «production-ready».
