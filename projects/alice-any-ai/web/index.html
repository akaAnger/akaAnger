Знакомый голос.
Твоя модель.

Подключи сторонний ИИ к приватному навыку Алисы. Без прошивки колонки и редактирования кода.

Вход в панель

На компьютере используй личную ссылку из окна запуска. В облаке скопируй ADMIN_TOKEN из переменных окружения сервиса. Это не ключ нейросети.

01

Выбери, кто отвечает

Документация выбранного сервиса

В списке могут быть не только чат-модели. Выбери текстовую. Если API не поддерживает список моделей, введи имя вручную.

Адрес и дополнительные настройки

Счетчик в памяти, по UTC; перезапуск его обнуляет. Это не денежный лимит. Настрой бюджет отдельно у провайдера.

Необязательно. Поддерживаются temperature, top_p, reasoning_effort, только если их принимает выбранная модель.

Кнопка проверки отправит выбранному ИИ фразу «Ответь одной короткой фразой: подключение работает». Провайдер может списать оплату за запрос. Подписка на сайт чата не заменяет оплату API.

02

Соедини с Алисой

Открой Яндекс Диалоги под аккаунтом Станции. Создай «Навык в Алисе» с приватным доступом. Придумай уникальное название из двух-трех слов без слов «Алиса», «Яндекс», «Станция».

Не адрес нейросети. Для локального запуска нужен работающий туннель. Обычный localhost Алисе недоступен.

Ограничить круг пользователей

Для первого запуска достаточно приватного навыка и секретного вебхука. Дополнительно можно разрешить конкретные идентификаторы session.user.user_id. Они не совпадают с почтой или логином.

03

Скопируй адрес и заговори

В адресе есть секрет доступа. Не публикуй его в постах, скриншотах и GitHub. Это не API-ключ модели.

Вставь адрес в поле Backend → Webhook URL. Проверь навык во вкладке Тестирование, отправь на автомодерацию и опубликуй с приватным доступом. Не включай требование экрана для колонки.

«Алиса, запусти навык [твое название]»

Если ИИ отвечает не сразу: «Ответ готов?». Длинные ответы: «Дальше». Начать без контекста: «Новая тема». Выйти: «Выход».

Неофициальный проект. Не заменяет Алису целиком и не управляет умным домом. Голос проходит через Яндекс, текст — через этот сервер и выбранного провайдера. Для секретов и паролей не использовать.
