## Что получится

> «Алиса, запусти навык [ваше название]»  
> «Объясни, почему у радуги такая форма»

Алиса распознает речь, этот проект отправит текст выбранной модели, а Станция озвучит ее ответ. Если модель думает дольше, спросите **«Ответ готов?»**. Не нужно повторно отправлять вопрос и платить за новую генерацию.

**Это отдельный навык, а не замена Алисы целиком.** Он не управляет музыкой, таймерами или умным домом. Вне навыка Станция работает как обычно.

## Подключить без программирования

| Путь | Что потребуется | Что важно |
|---|---|---|
| **[В облаке](docs/CLOUD.md)** | Аккаунт хостинга, ключ API, Яндекс-аккаунт | Настройка в браузере; шаблон использует платный тариф и постоянный диск. Компьютер можно выключать. |
| **[На компьютере](docs/LOCAL.md)** | Node.js, cloudflared, ключ API или Ollama | В Windows запуск через `start.bat`. Компьютер должен работать, временный HTTPS-адрес меняется после перезапуска туннеля. |

**Самый короткий путь в облаке:**

1. [Создайте свой экземпляр на Render](https://render.com/deploy?repo=https://github.com/akaAnger/akaAnger). Проверьте стоимость Starter и диска до подтверждения.
2. Откройте его адрес. Войдите с `ADMIN_TOKEN` из Environment этого экземпляра.
3. В панели выберите сервис, вставьте его API-ключ, укажите модель и нажмите проверку связи. Проверка может быть платной.
4. [Создайте приватный навык](docs/YANDEX.md), вставьте его ID в панель и сохраните настройки.
5. Перенесите полученный Webhook URL в Яндекс Диалоги, протестируйте и опубликуйте навык.

Подробно, с пояснением каждого поля: **[инструкция для новичка →](docs/CLOUD.md)**

## С какими ИИ

| Вариант | Как подключается |
|---|---|
| DeepSeek | Совместимый Chat Completions API |
| OpenRouter | Совместимый API; конкретные доступные модели зависят от аккаунта |
| OpenAI | Chat Completions API, отдельный API-ключ и биллинг |
| Google Gemini | Официальный OpenAI-совместимый endpoint |
| Anthropic Claude | Нативный Messages API |
| Ollama | Совместимый локальный API на вашем компьютере |
| Другой сервис | Формат Chat Completions или Anthropic Messages; настраиваемые адрес и модель |

Название **Any AI** означает возможность выбирать провайдера, **не гарантию совместимости с любым сайтом или моделью**. Нужен доступный текстовый API одного из реализованных форматов. Azure/Bedrock с их собственной авторизацией, нестандартные API, только Responses API, сайты без API и инструменты моделей не поддерживаются напрямую. Для них потребуется совместимый шлюз либо отдельный адаптер.

Пресет — готовая конфигурация формата, а не отметка о ручном тесте всех моделей поставщика. Введите точное имя реально доступной чат-модели; приложение не фиксирует устаревающие названия моделей. Список `/models` доступен не у всех API.

[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) · [Gemini](https://ai.google.dev/gemini-api/docs/openai) · [Anthropic](https://platform.claude.com/docs/en/api/messages/create) · [Ollama](https://docs.ollama.com/api/openai-compatibility) · [DeepSeek](https://api-docs.deepseek.com/) · [OpenRouter](https://openrouter.ai/docs/api-reference/overview)

## Что уже есть

**Панель настройки.** Выбор сервиса, список моделей, тест подключения, понятные ошибки, настройка ID навыка и готовый Webhook URL. Код редактировать не нужно.

**Ожидание медленной модели.** Один запрос к ИИ продолжает выполняться после короткого ответа навыка. Команда «Ответ готов?» получает его результат. Проекту нужен постоянно работающий процесс, не одноразовая serverless-функция.

**Разговор с контекстом.** Ограниченная история текущей сессии, «Новая тема», «Отмена», «Повтори», выдача длинного ответа частями по команде «Дальше». Истории разных сессий разделены.

**Контроль доступа и расходов.** Отдельные секреты панели и вебхука, проверка ID навыка, опциональный список пользователей, кеш повторов, ограничения частоты и числа запросов. Денежный лимит дополнительно настраивается у провайдера.

**Инструкции и тесты.** Локальный запуск, Render, Docker, безопасность, диагностика и автоматические проверки без действующих ключей. Docker-образ не содержит инструментов установки из случайных скриптов.

## Ограничение Алисы: 4,5 секунды

[Яндекс Диалоги](https://yandex.ru/dev/dialogs/alice/doc/ru/publish-settings) ждут ответ не более 4,5 секунды с учетом сети. По умолчанию приложение дает модели 1,5 секунды, затем возвращает фразу об ожидании. Это оставляет запас, но **не гарантирует**, что любой сетевой маршрут или холодный сервер уложится в общий срок.

Колонка не заговорит сама после долгого ожидания: пользователь должен сказать **«Ответ готов?»**. Длина одной реплики ограничена [1024 символами](https://yandex.ru/dev/dialogs/alice/doc/ru/response); длинный ответ делится на части.

## Бесплатно или платно?

Код распространяется по MIT, платить автору за использование не нужно. Но облачное размещение, API-запросы и электроэнергия для локального ИИ могут стоить денег. Условия и доступность зависят от провайдера, страны и выбранной модели.

Обычная подписка ChatGPT не является балансом API: [API оплачивается отдельно](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus). Не вводите пароль от аккаунта чата вместо API-ключа.

## Что с приватностью

Ключ хранится на **вашем экземпляре** в `.data/config.json`, а не в GitHub и не у автора проекта. Файл не зашифрован приложением: защищайте сервер и резервные копии. Полный Webhook URL и личная ссылка администратора тоже секретны.

Локальная Ollama **не делает Алису офлайн**: голос проходит через Яндекс. При облачной модели текст вопроса и ограниченный контекст получает ИИ-провайдер. Не диктуйте пароли, платежные сведения и рабочие секреты.
