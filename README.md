## Featured projects

### PeerCall

A lightweight PWA for private one-to-one browser audio calls using WebRTC.

- No accounts
- No backend signaling
- Manual one-time connection codes
- PWA support
- Privacy-focused architecture

### Stena

A Telegram Mini App prototype for collecting Telegram channel posts into one clean feed.

The project focuses on:

- Telegram source aggregation
- duplicate post detection
- readable feed UI
- AI-assisted post titles
- feedback-based deduplication improvements

### Retro'98 Microgames

A collection of small browser games inspired by the Windows 98 interface.

- Vanilla HTML, CSS, and JavaScript
- No build step
- No external assets
- Local-only saves
- Retro UI experiments

### LRC Sync Player

A small Python terminal app for playing local audio with synchronized `.lrc` lyrics.

- MP3 playback
- LRC timestamp parsing
- animated terminal lyrics
- configurable sync offset
